- `git status` — показывает репозиторий и какие файлы заккомичены и сохранены, а какие нет
- `git add` — подготавливает файл к коммиту
- `git commit` — добавляет изменения из git add в историю репозитория
- `git push` — отправляет коммиты в репозиторий
- `git pull` — устанавливает все изменения из репозитория
- `git branch` — показывает текущую ветку
- `git checkout` — переключает ветку, -b делает так, что сразу еще и создает ветку
