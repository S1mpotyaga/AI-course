# Лабораторная 2. Статистика на отрезках

Сначала нужно решить три простые задачи на понимание статистических метрик, а затем пять алгоритмических задач в стиле Codeforces.

В работе используются темы из первой лабораторной:

- среднее;
- дисперсия;
- стандартное отклонение;
- коэффициент асимметрии;
- префиксные суммы `x`, `x²`, `x³`.

## Что делать

1. Откройте `lesson_02_statistics.ipynb`.
2. Решите задачи 0A–0C на понимание среднего, стандартного отклонения и асимметрии.
3. Затем реализуйте `build_prefixes`.
4. После этого решайте задачи A–E по порядку.
5. После каждой задачи запускайте ячейку с тестами.
6. Не меняйте файлы в папке `tests`.
7. Перед сдачей перезапустите ядро и выполните весь ноутбук сверху вниз.

Главная идея работы: префиксы строятся один раз за `O(n)`, после чего
статистики каждого отрезка должны находиться за `O(1)`.
При `q` запросах итоговая сложность должна быть `O(n + q)`.
