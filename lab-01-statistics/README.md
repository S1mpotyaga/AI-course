# Лабораторная работа № 1. Статистика и префиксные суммы

В этой работе вы самостоятельно реализуете статистические функции на Python и научитесь быстро отвечать на запросы к отрезкам массива и прямоугольникам матрицы.

## Что нужно сделать

Работайте в блокноте `lesson_01_statistics_tasks.ipynb`:

- Вычислите среднее, медиану, дисперсию, стандартное отклонение, начальные и центральные моменты, коэффициент асимметрии.
- Исследуйте, как сдвиг, умножение значений и выбросы влияют на статистики. Запишите прогнозы и выводы.
- Постройте префиксные суммы и реализуйте вычисление статистик на отрезке за `O(1)` после предварительной обработки.
- Решите задачи «Асимметричная набережная» и «Сумма на прямоугольнике», используя одномерные и двумерные префиксные суммы.
- Ответьте на вопросы в текстовых ячейках. Дополнительно выполните эксперимент по измерению ускорения.

## Как работать

1. Откройте блокнот в Jupyter или VS Code с поддержкой Python и Jupyter. Выберите ядро Python.
2. Выполняйте ячейки сверху вниз (`Shift+Enter`). В заготовках заменяйте `raise NotImplementedError` своим кодом и убирайте выполненные пометки `TODO`.
3. После реализации функции запустите ячейку с её определением, затем следующую ячейку проверки. После исправлений повторите оба запуска.
4. Заполните текстовые ответы и сохраните блокнот.

Проверки запускаются прямо из ноутбука, например:

```python
%run -i ./tests/check_mean.py
```

Результат появится под ячейкой. `AssertionError` означает, что одна из проверок не пройдена: прочитайте сообщение и исправьте решение. 

## Правила реализации

- Используйте обычный Python и свои ранее написанные функции. Не заменяйте решения готовыми статистическими функциями NumPy, pandas или SciPy.
- Сохраняйте имена функций и параметры из заготовок: от них зависят автоматические проверки.
- Не изменяйте исходные списки. Соблюдайте требования к сложности из условий.
- Дисперсию и моменты считайте с делением на `n`, а не на `n - 1`. Не округляйте промежуточные вычисления.
- В запросах границы нумеруются с **1** и включаются в результат. Префиксы стройте один раз, а не заново для каждого запроса.

## Перед сдачей

Перезапустите ядро, выполните все ячейки сверху вниз и проверьте итоговый отчёт в конце блокнота. Сохраните `.ipynb` с решениями, результатами запусков и письменными ответами.

Будьте готовы объяснить свой алгоритм и оценить его время работы и расход памяти. Успешные тесты не заменяют объяснение решения.
