# Лабораторная 0. Первые шаги в Git и GitHub

**Цель:** научиться создавать и редактировать файлы через сайт GitHub и терминал,
сохранять изменения в коммитах, синхронизировать локальный репозиторий и сдавать работу через Pull Request.

## 0. 

Из ветки `main` выполните команду `git pull`. Далее создайте свою ветку с именем `<surname>-lab-00-<name of task>` (правила названия веток написаны в ветке main). 

## 1. Создайте два файла через интерфейс GitHub

Находясь в ветке `<surname>-lab-00-<name of task>`, выберите **Add file → Create new file**.

### Файл info.md

Создайте в корне репозитория файл `info.md`. Используйте структуру:

```markdown
# Обо мне

## Имя
Здесь напишите своё имя, никнейм на гитхабе и свой класс.

## Опыт
Здесь ответьте на несколько вопросов:
1. Занимались ли вы в каких-нибудь кружках по математике или программированию?
2. Что вы знаете об искусственном интеллекте?
3. Почему вы пришли на этот кружок?
4. Хотите ли участвовать в хакатонах по ИИ?
```

Нажмите **Commit changes**, укажите сообщение `add info` и сохраните изменения **в текущую ветку `<surname>-lab-00-<name of task>`**.

### Файл goals.md

Таким же способом создайте `goals.md`:

```markdown
# Мои ожидания

- Напишите первую хотелку
- Напишите вторую хотелку
- Напишите третью хотелку
```

Запишите свои ожидания, пожелания или хотелки в таком формате. Каждый пункт начинается с `- `.
Сохраните отдельным коммитом с сообщением `add goals`.

## 2. Создайте файлы локально и отправьте их через Git

В терминале, внутри ветки `<surname>-lab-00-<name of task>`, создайте заготовку файла:

```bash
cat > commands.md
```
Откройте `commands.md` в редакторе и после каждого тире **своими словами** объясните команду.
Сохраните файл. Пустые пояснения не засчитываются.

- `git status` — 
- `git add` — 
- `git commit` — 
- `git push` — 
- `git pull` — 
- `git branch` — 
- `git checkout` — Здесь укажите, что обозначает флаг -b.

Теперь в интерфейсе VS Code создайте папку `image` и вставьте туда картинку с названием `test.png`.
Далее откройте файле `.gitignore` и укажите в новой строке `image/test.png`.

Выполните по очереди:

```bash
git status
git add commands.md .gitignore image/test.png
git commit -m "add git notes and ignore rules"
git push -u origin <surnmae>-lab-00-<name of task>
```

Если вторая команда не выполняется, то в файле `commands.md` объясните в чем ошибка и что за файл `.gitignore`. Затем уберите из `.gitignore` последнюю строку `image/test.png`. И снова выполните предыдущие команды.

Откройте ветку `<surname>-lab-00-<name of task>` на GitHub и убедитесь, что все файлы появились.

## 5. Откройте Pull Request и посмотрите проверку

На GitHub нажмите **Compare & pull request** или **Pull requests → New pull request**.

Заголовок: `Лабораторная 0 — ваш ник`.

Во вкладке **Files changed** проверьте свои изменения. Во вкладке **Checks** найдите свои результаты :)

Если проверка красная, прочитайте сообщение, исправьте файл и сделайте новый commit/push
**в ту же ветку**. Существующий PR обновится, проверка запустится снова.

## Что проверяется

Все файлы должны лежать **в корне репозитория**, быть обычными текстовыми файлами и не быть пустыми.
