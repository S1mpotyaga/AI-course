# Вводное задание

Привет! Это кружок по подготовке ко ВСОШ по ИИ. Здесь описано, как выполнять задания и как проверять решения. А сами задания описаны в нужных вам папках.

Для работы с этим репозиторием выполните следующие пункты:

1. Установите VS code на свой компьютер.
2. Создайте папку на своем компьютере, где будут хранится все задания;
3. Откройте VS Code и откройте в нем папку, созданную в предыдущем пункте;
4. Теперь откройте терминал. Для этого слева сверху найдите вкладку View (Вид) и в ней выберете Terminal (Терминал);
5. В терминале напишите следующую команду (или просто скопируйте): `git clone https://github.com/S1mpotyaga/AI-course.git`. 

## Как теперь выполнять задания?

После выполнения предыдущих пунктов у вас есть на локальном компьютере появился репозиторий, куда я буду выкладывать все задания для практических занятий.
Я перед практическим занятием буду выкладывать в ветку `main` новую папку с описанием задания в файлике `README.md`, а так же с нужными вам jupiter ноутбуками для выполнения заданий. Чтобы выполнить задание сделайте следующее:

1. В терминале VS Code перейдите в ветку `main` с помощью команды `git checkout main`. Вы перейдете в ветку `main`.
2. Далее выполните команду `git pull`. Таким образом вы подтяните к себе на локальный компьютер все изменения в ветке `main`. После этого шага у вас слева в окне `Explorer` должна появиться новая папка, название которой начинается с `lab-<number>-<name of task>`, где `<number>` порядковый номер задания, который будет меняться от задания к задания в порядке возрастания, а `<number of task>` - названия задания/урока.
3. Теперь ОБЯЗАТЕЛЬНО выполните команду `git checkout -b <surname>-lab-<number>-<name of task>`, где `<surname>` - ваша фамилия на английском языке, а `<number>` и `<name of task>` из предыдущего пункта. Так вы создадите свою ветку, в который ДОЛЖНЫ выполнять задания. 
4. Теперь открывайте файл с расширением `.ipynb` и выполняйте задания, написанные в этом ноутбуке.

## Как проверить, что все правильно?

Для тестирования ваших решений предусмотрена автоматическая проверка. Чтобы ее запустить сделайте следующее:

1. Если вы уверены, что вы сделали все правильно и проверка в ноутбуке выполнена выполните команду `git add <names files>`, 
где `<names files>` - имена измененных/созданных файлов. Можно выполнить команду `git add .`, и тогда сразу добавяться все файлы из текущей папки, в которой вы находитесь. !!!БУДЬЕ ВНИМАТЕЛЬНЫ, В КАКОЙ ДИРЕКТОРИИ ВЫ НАХОДИТЕСЬ.
2. Чтобы проверить, что все файлы добавились в git, выполните команду `git status`. После выполнения этой команды в терминале вы должны увидеть имена файлов, которые добавлены в git. Те файлы, которые добавлены будут выделены зеленым цветом, которые не добавлены - красным. !!!СМОТРИТЕ ВНИМАТЕЛЬНО, КАКИЕ ФАЙЛЫ ВЫ ДОБАВЛЯЕТЕ В GIT.
3. Теперь нужно создать коммит. Выполните команду `git commit -m "<name of commit>"`, где `<name of commit>` - имя вашего коммита, где вы должны КРАТКО указать, что вы сделали. Например, `git commit -m "работа выполнена"`.
4. Дальше нужно отправить ваше решение на проверку. Для этого выполните команду `git push origin <name of branch>`, где `<name of branch>` - имя вашей ветки, в которой вы выполняли работу. Чтобы посмотреть имя ветки, в которой вы работаете выполните команду `git branch`. Зеленым цветом будет выделено имя ветки, в которой вы работаете.
5. Далее откройте гитхаб и перейдите в наш репозиторий. Сверху у вас будет вкладку `Pull Requests`. Перейдите туда.
6. Нажмите кнопку `Create new pull requst`. Выберете в качестве `target branch` ветку `main`, а в качестве `source branch` именно вашу ветку. И нажмите внизу кнопку `Create`. 
7. Вас должно перенести на страницу вашего пул реквеста. Вверху откройте вкладку `Actions`. Если вы увидите зеленую галочку, значит, что все хорошо и верно выполнили задание. Если Увидите красный крестик, значит есть ошибки. Чтобы посмотреть, где ошибка, нажмите на прямоугольник с запуском. Там будет вся информация о тестировании вашей работы.
